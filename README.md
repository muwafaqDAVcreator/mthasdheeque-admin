# mthasdheeque Admin Panel

Professional admin dashboard for managing mthasdheeque.com portfolio content.

## Features

- 🔐 JWT authentication
- 📊 Dashboard with statistics
- 📁 Projects management
- 📝 Blog management
- ⭐ Testimonials management
- 🎯 Skills management
- 💬 Contact messages
- 📧 Newsletter subscribers

## Development

```bash
npm install
npm run dev
```

Visit http://localhost:5173
